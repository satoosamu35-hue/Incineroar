# MY GAME
This is my game.
This game is based on a real concept I'm making with my two best friends called Desert Dynasty. 
Right now, it's a small text-based game meant to show the storyline idea and how it's going to go.
Currently, I only have 3 worlds done due to time constraints, but I believe I got out the best that I possibly could.
This game is a text-based game that requires reading and battle progression. This game is a rogue-like one; if you "fall" in the game, then you must restart from the beginning.


+=====================================================

THERE ARE NO SAVE SPORTS IF YOU DIE TEH GAME WILL CLOSE AND YOU START OVER!!!!!!!!!!!!!!

==================================================
The game progresses by you completing puzzles, exploring, and battling while maintaining your health.
Puzzles include word unscrambling and riddles
Exploring is not a super important part; you don't have to explore certain places if you don't wish to, but I suggest it for some somewhat funny dialogue
